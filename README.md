# Portal Web • N3xx-us

Sitio web estático adaptable a PC y móvil con modo rendimiento (animaciones ON/OFF) y selector de tema Blanco / Negro.

## Estructura de carpetas

- `./index.html` — Portal principal con selector de tema, modo PC/Móvil y accesos rápidos.
- `./NovaPlay/` — Hub de juegos y herramientas en el navegador.
- `./Minecraft/` — Página de **NexCraft** (`NexCraftBedrock.aternos.me` y `NexCraftJava.aternos.me`), reglas y noticias.
- `./Perfiles/` — Enlaces y botones de copia para YouTube (`@N3xx-us`), Discord, Twitch (`n3xx_us`), Bloxd.io (`N3xxs-US`), Chess.com (`n3xx_us`) y Scratch (`N3xx_Us_Oficial`), más widget de Discord (`1572756862607036538`).
- `./ClassiCube/` — Página de **NexCube** con estética clásica morada, reglas y novedades.

## Publicación en GitHub Pages

1. Sube los archivos extraídos del `.zip` a la rama principal del repositorio.
2. Ve a **Settings → Pages**.
3. Selecciona la rama principal y la carpeta `/(root)` y guarda para publicar.
